Studio Spec

HR4E Studio is the web-based environment for working with HR4E vaults. It provides a unified place to view, edit, extract, and eventually analyze vault contents. Studio is designed to operate offline-first, but not offline-only, allowing clinicians and patients to work with vaults even when connectivity is limited while still supporting synchronization when available.

Current Capabilities (Alpha)

The present Studio implementation is an alpha version intended for early testers. It includes:

  • Editor/Viewer — a basic interface for viewing and editing CCD-subset documents.
  • Extractor/Loader — a deterministic tool for generating vault contents from structured inputs.

The current design is not yet modular. Editor/Viewer and Extractor/Loader are implemented as tightly coupled components, suitable for prototyping but not for long-term extensibility.

Relationship to the Foundation Layer

Studio corresponds to the “configurable web-based environment” described in the HR4E Foundation Layer. Over time, Studio will integrate additional tools — Analyzer/Reporter, Biller/Bookkeeper, and modular Extractor/Loader profiles — providing a single interface for working with vaults across clinics, schools, and patient-carried eHP workflows.

Future Roadmap

  • Modular tool architecture (Editor, Extractor, Reporter, Biller as independent modules)
  • Offline-first synchronization workflows for eHP and clinic vaults
  • Configurable Extractor/Loader profiles for different EHR systems
  • Support for encounter summaries, immunization tracking, and school health workflows
