HR4E Studio

HR4E Studio is a web-based environment for working with HR4E vaults. The current alpha version provides an Editor/Viewer for CCD-subset documents and a deterministic Extractor/Loader for generating vault contents from structured inputs. Studio is not yet modular, but it serves as a functional prototype for the broader HR4E toolchain.

The Studio source code is available in the HR4E GitHub organization:

hr4e-revisited/studio

Over time, Studio will evolve into a configurable, offline-first environment supporting modular tools for editing, extraction, reporting, and billing. The current version is intended for developers and early testers who want to explore the HR4E Foundation Layer.
