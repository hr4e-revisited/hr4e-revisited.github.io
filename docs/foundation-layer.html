Overview

The foundation layer defines the core artifacts and flows that all HR4E deployments share: vault format, studio behavior, extractor/loader contracts, and billing/reporting primitives.

Components

  • Vault specification (document types, metadata, FHIR mapping).
  • Studio web-app (Editor/Viewer, Extractor/Loader, Analyzer/Reporter).
  • Deployment profiles (clinic, school, relief setting).
